# Support

Start with the documentation index in [docs/README.md](docs/README.md), then check:

- [Concepts](docs/concepts.md) for the shape of observation and verification results;
- [Operation outcomes](docs/operation-outcomes.md) for unknown or inconclusive writes;
- [Reliability and recovery](docs/reliability.md) for installation, reconnect and retry behavior;
- [Browser evaluation](docs/browser-evaluation.md) for the supported deterministic scenarios.

Use [GitHub Discussions](https://github.com/wklwkl115/browser-pilot/discussions) for usage questions, design exploration and examples. Use the bug report issue form for a reproducible project problem, and the feature request form for a concrete proposal.

When asking for help, include the Browser Pilot version, Node.js version, operating system, browser and the exact command or MCP call. Redact passwords, pairing secrets, cookies, private URLs, page text and network bodies before sharing logs or screenshots.

Security reports do not belong in Discussions or public issues. Follow [SECURITY.md](SECURITY.md).
