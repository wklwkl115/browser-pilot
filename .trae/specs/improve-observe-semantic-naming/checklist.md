# Checklist

- [x] observe/ABML 存在统一或等价的安全语义文本清洗逻辑。
- [x] SVG/path/HTML-like 字符串不会进入 `entity.name`、ref semantic name 或 textAnchor locator。
- [x] editable 字段仍不会把 runtime value 提升为 `entity.name` 或 `entity.value`。
- [x] list hint 采集不会把纯 SVG/path outerHTML 当作可推广语义名称。
- [x] list hint 能表达安全 container label 或等价容器语义候选。
- [x] list region entity name 优先使用安全 container label，缺失时使用安全 fallback。
- [x] `collection.containerName` 不再直接使用未清洗 first item preview。
- [x] first item preview 只作为 sample/evidence，不作为 authoritative container name。
- [x] icon/SVG-heavy 控件优先使用 aria/title/alt/labelled-by/sr-only 等安全可访问文本。
- [x] icon/SVG-heavy 控件无安全名称时不会暴露 SVG/path markup。
- [x] scan summary display name 与 ABML entity semantic name 的安全候选策略保持一致或有明确分层理由。
- [x] 新增或更新测试覆盖 SVG/path/HTML-like 候选过滤。
- [x] 新增或更新测试覆盖 `containerLabel` 优先和 collection safe fallback。
- [x] 新增或更新测试覆盖 icon-heavy control 的 accessible label 行为。
- [x] no-mode `browser_observe` 仍保持 canonical PageObservation 路径，不引入 legacy mode 回退。
- [x] 实际 Edge 页面复验中，observe artifact 的 collections/entities/actionables 不再把 `<path ...>` 作为语义名称。
- [x] 相关 focused tests 已通过。
- [x] `mise run affected` 或符合仓库规则的相关 gate 已通过。
- [x] `mise run verify` 已通过，或有明确记录说明无法运行的原因与剩余风险。
