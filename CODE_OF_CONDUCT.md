# Code of Conduct

## Our standard

We want Browser Pilot discussions and contributions to be useful, specific and welcoming. Participants are expected to:

- be respectful and assume good intent while resolving technical disagreement;
- focus criticism on the idea, code or evidence rather than the person;
- explain constraints and trade-offs clearly;
- respect privacy, consent and the security boundaries of browser sessions;
- avoid harassment, discrimination, doxxing, spam and deliberately disruptive behavior.

## Scope

This code applies in repository issues, pull requests, discussions, reviews, documentation and project spaces used for Browser Pilot work. It also applies when someone is representing the project in another public space.

## Enforcement

Maintainers may edit, hide or close content and may restrict participation when conduct violates this code or threatens another person's privacy or safety. For a sensitive concern, use GitHub's private vulnerability reporting flow and do not include private evidence in a public report.

We will handle reports as privately as practical and will explain the decision when doing so does not create another safety or privacy risk.

## Attribution

This policy is intentionally concise and follows the principles of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
